# 佛山空域测试说明

## 结论先看

- 当前项目的禁飞区判断方式是：`经纬度 + 半径 + 高度 + 生效状态` 的本地规则命中。
- 当前测试环境使用的是 `no_fly_zones` 表中的本地样本数据，不是官方实时禁飞数据库。
- 本文档补充的是一组 `佛山市内可演示的测试样本`，只用于验收和联调，不代表真实官方空域结论。

## 最容易走通的测试点

### 1. 直接拦截：祖庙博物馆

- 搜索关键词建议：`佛山市祖庙博物馆`、`祖庙`
- 命中后预期：
  - 表单出现 `禁飞拦截`
  - 按钮禁用
  - 提示“当前位置命中禁飞区域，请更换地址后再继续下单或发布任务”

### 2. 只提醒不拦截：千灯湖

- 搜索关键词建议：`千灯湖`、`千灯湖公园`
- 命中后预期：
  - 表单出现 `限飞提醒`
  - 可以继续提交
  - 会提示提前确认报备与飞行限制要求

### 3. 只提醒不拦截：顺峰山

- 搜索关键词建议：`顺峰山公园`
- 命中后预期：
  - 表单出现 `检测通过` 以外的风险提示
  - 可继续
  - 详情页应显示 `注意区`

### 4. 直接拦截：三水广场

- 搜索关键词建议：`三水广场`
- 命中后预期：
  - 表单出现 `禁飞拦截`
  - 不能继续提交

### 5. 直接拦截：沙堤机场

- 搜索关键词建议：`佛山沙堤机场`
- 命中后预期：
  - 表单出现 `禁飞拦截`
  - 不能继续提交

## 适合验证的页面

- 快速下单页
- 发布任务页
- 直达下单确认页
- 禁飞区详情页 `查看附近飞行限制`

## 建议验证顺序

1. 先测 `佛山市祖庙博物馆`
   - 验证 `no_fly` 会不会直接拦截
2. 再测 `千灯湖`
   - 验证 `restricted` 是否只提醒不阻断
3. 再测 `顺峰山`
   - 验证 `caution` 是否只提醒不阻断
4. 最后测 `沙堤机场`
   - 验证大半径禁飞区是否也能稳定命中

## 相关接口

- 列表：`GET /api/v1/airspace/no-fly-zones`

- 检测：`GET /api/v1/airspace/check-availability?latitude=...&longitude=...&altitude=120`
